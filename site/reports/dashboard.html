Usage numbers refresh weekly from site/stats/*.json (the Ops · Site stats workflow), which appends one dated row per run to site/reports/stats/history.json. The downloads trend is anchored at each release date (v0.1.0 starts the series at zero) and grows as snapshots accrue; hover a point for its date and total. Quality runs come from site/reports/runs.json (the Ops · Quality reports workflow and local pnpm report runs): each records the gates (Rust tests, clippy, rustfmt, ESLint, the runtime harness, cargo audit), lint and complexity debt, code size, the QA matrix, localization and docs pairing, and how long each step took. Platform coverage reads the QA matrix the lab assembles (site/reports/qa/matrix.json). Charts need at least two runs carrying a signal before they draw.
