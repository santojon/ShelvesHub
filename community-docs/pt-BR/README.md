# Docs da comunidade — prontas para publicar

*[Read in English](../README.md)*

Um arquivo por tópico, escrito para GitHub Discussions, anúncios no Discord e
posts no Reddit — não são notas internas. Cada um explica o que o recurso faz,
por que você iria querer, exatamente como ligar/desligar e como resolver
problemas, em linguagem simples que um usuário (não um contribuidor) consegue
seguir.

Copie o conteúdo de um arquivo direto para uma Discussion / post no Discord /
post no Reddit. Corte a seção "Resolução de problemas" para um anúncio curto se
quiser; mantenha-a para uma Discussion fixada que as pessoas vão pesquisar
depois.

## Índice

**Comece por aqui**
- [getting-started.md](getting-started.md) — o que é o ShelvesHub, como instalar, onde ficam as configurações
- [installing.md](installing.md) — os passos exatos de instalação e desinstalação por plataforma

**Convivendo com ele**
- [quick-access-panel.md](quick-access-panel.md) — o painel de gerenciamento que o ShelvesHub adiciona ao Menu de Acesso Rápido
- [automatic-updates.md](automatic-updates.md) — manter o ShelvesHub e o Deck Shelves atualizados, com canais de pré-lançamento
- [coexistence.md](coexistence.md) — rodar o ShelvesHub ao lado de um carregador de plugins na mesma máquina
- [data-backend.md](data-backend.md) — como lista de desejos, preços e recursos de dispositivo funcionam sem carregador instalado

**Extras opcionais**
- [boot-animation.md](boot-animation.md) — uma animação de inicialização opcional do Deck Shelves reproduzida pelo Steam
- [desktop-shelves.md](desktop-shelves.md) — experimental: mostrar as prateleiras também no cliente desktop comum

**Quando algo dá errado**
- [troubleshooting.md](troubleshooting.md) — nada aparece, uma tela preta, um conflito de porta, ler o log

Tudo acima é opcional e desativado por padrão, a menos que o arquivo diga o
contrário. Versões atuais: ShelvesHub v0.1.0+, Deck Shelves v3.3.0+.
