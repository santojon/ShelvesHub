# Community docs — ready to post

*[Leia em português](pt-BR/README.md)*

One file per topic, written for GitHub Discussions, Discord announcements,
and Reddit posts — not internal notes. Each one explains what the feature
does, why you'd want it, exactly how to turn it on/off, and how to
troubleshoot it, in plain language a user (not a contributor) can act on.

Copy a file's content straight into a Discussion / Discord post / Reddit
post. Trim the "Troubleshooting" section for a short announcement if you
want; keep it for a pinned Discussion post people will search later.
